Windows 10/11

Native installer
  1. Download and open GraphicRunnerInstallBeta.exe.
  2. Verify its SHA-256 checksum:DAB122180897319829DEB4BFE37B888F726932AFCFB2EAD74D34A6438BBBFA8A
  3. This unsigned beta may display Windows protected your PC. After verifying the checksum, select More info, confirm the app name, then select Run anyway.
  4. Finish installation and launch Graphic Runner from its shortcut or Start menu entry.

Do not disable Defender or SmartScreen. Trusted code signing is the permanent fix for the warning.

Linux

Tested through Wine
  1. Install Bottles from Flathub and complete its first-run setup.
  2. Create a 64-bit Application bottle named Graphic Runner.
  3. Choose Run Executable and select GraphicRunnerInstallBeta.exe.
  4. Complete installation, then launch Graphic Runner from the bottle's Programs list.

Direct Wine alternative: wine GraphicRunnerInstallBeta.exe. This is a tested compatibility setup, not a native Linux package.
