# Graphic Runner v0.2.0 Public Beta

This release expands the private-source, self-contained C#/.NET desktop build.

## Highlights

- Faster live masking and layer-opacity previews with full-quality final renders.
- Clear-canvas startup and corrected responsive splash typography.
- Raster **Image** mode plus a new **Logo Vector** builder.
- Multiple vector rectangles, ellipses, triangles, and stars with editable color, size, position, and rotation.
- Unite, Subtract, Intersect, and Exclude Pathfinder operations.
- Shape, color, and freehand selection workflows for images and vector logos.
- Lossless PNG export remains the default.
- SVG export keeps neutral Logo Vector artwork as vector paths and embeds lossless PNG data when pixel effects or raster artwork are present.
- Ctrl+wheel zoom, middle-button panning, arrow-key navigation, blend modes, masks, image upscaling, extrusion, and native Windows/Linux builds.

Application source code is private and is not included in this repository or the downloadable packages.
